# Private material

This folder keeps personal material with the project it belongs to without
allowing that material into the knowledge base. Nothing below `private/` is
ever read by `/ingest` or propagated by `/sync`, and no knowledge is derived
from it.

File general career material directly below `private/<person-slug>/`. Use
`private/<person-slug>/outputs/<event-slug>/` for dated application
deliverables. Use `private/unsorted/` only until a person can be identified
safely.
