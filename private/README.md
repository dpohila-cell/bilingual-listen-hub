# Private material

This folder keeps personal material with the project it belongs to. It is
ordinary project material: `/ingest` reads it and `/sync` propagates what is
derived from it (decided 2026-10-12). The only boundary is publication outwards.
A live password, key or token is never stored here.

File general career material directly below `private/<person-slug>/`. Use
`private/<person-slug>/outputs/<event-slug>/` for dated application
deliverables. Use `private/unsorted/` only until a person can be identified
safely.
